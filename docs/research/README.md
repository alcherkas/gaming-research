# Research

Supporting material for the project's architecture — the procedures, evidence, and reference
data that don't belong in the structural [`ARCHITECTURE.md`](../../ARCHITECTURE.md) but underpin
it. All of it concerns shipping a Unity 6 physics multiplayer game from an Apple Silicon Mac to
the Steam Deck (native Linux).
