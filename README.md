# gaming-research

Research and architecture for shipping a **Unity 6 physics multiplayer game** as a
**native-Linux Steam Deck title**, developed entirely from an **Apple Silicon MacBook** (no
Windows machine).

- **[`ARCHITECTURE.md`](ARCHITECTURE.md)** — the system architecture: runtime stack (Unity 6 +
  FishNet + Steamworks P2P + Vulkan/URP) and the Mac → Linux → Steam Deck build/deploy pipeline.
- **[`docs/research/`](docs/research/)** — supporting material: deployment runbooks,
  troubleshooting, caveats & roadmap, and version/pricing data.
